A `.cnmly` file is a Cinemaly travel capsule. It is the mobile format Cinemaly
uses to package a trip so the route, stops, photos, notes, and presentation data
can travel together.

That sounds technical, but the idea is simple: one trip, one portable memory
file.

## Why Cinemaly Uses a Capsule File

Most travel memories are scattered. Photos live in a camera roll. Notes live in
a notes app. Routes live in a map app. When you try to share the trip later,
the story falls apart.

A capsule keeps the pieces together.

<Callout>
  A `.cnmly` file is not meant to be a generic photo album. It is a Cinemaly
  travel capsule designed to open in Cinemaly.
</Callout>

## What Is Inside a Capsule?

<Step num="01" title="The route">
  The capsule keeps the order of your stops so the journey still has a shape.
</Step>

<Step num="02" title="Photos and notes">
  Photos and director notes stay attached to the places where they belong.
</Step>

<Step num="03" title="Presentation settings">
  Cinemaly can use capsule data to replay the trip as a cinematic map story.
</Step>

## .cnmly vs .html on the Web

The Cinemaly web compiler can create a portable `.html` capsule because it runs
inside a browser. The mobile apps use `.cnmly`, a dedicated package format built
for app-based creation and sharing on iPhone and Android.

## How Do Friends Open It?

Friends need Cinemaly to open a `.cnmly` capsule. Send them the file, point them
to the app, and they can open the trip inside Cinemaly.

## Privacy Notes

Cinemaly does not upload your capsules, photos, notes, or videos to a Cinemaly
server. A capsule is a file you can keep, back up, or share yourself.
